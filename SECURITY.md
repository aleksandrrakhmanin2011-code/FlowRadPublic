# FlowRad Public

Публичный статический веб-радар FlowRad.

## Структура

- `index.html` — страница радара
- `css/style.css` — стили интерфейса
- `js/app.js` — логика карты, источников и анимации
- `assets/icons/` — локальные иконки
- `assets/images/` — дополнительные изображения проекта
- `.github/workflows/` — GitHub Actions

## Данные

Используются общедоступные источники RainViewer, RainRadar.ru, РГМЦ / Meteoinfo и публичные картографические тайлы.

Секретные API-ключи в проект не включены.

## Развёртывание

Проект предназначен для обычного статического хостинга или GitHub Pages. Backend для текущей версии не требуется.

## Безопасность

Не добавляйте API keys, Telegram tokens, пароли, сертификаты или `.env` в репозиторий. Если позже появится приватный API-ключ, вынесите его на серверную сторону / Cloudflare Worker.
